Architecture & Dependencies

A technical overview of runtime components, local storage, and network behavior in MySoundLib.

Runtime Stack & Libraries

MySoundLib is distributed as a standalone desktop binary. It runs directly on your operating system without web runtimes or background servers.

Component Role
PySide6 (Qt) Native windowing, hotkey overlays, audio output subsystem, and OS drag-and-drop.
soundfile (libsndfile) C-based PCM stream decoding and waveform sample extraction.
NumPy Vectorized waveform peak calculations and buffer downsampling.
pydub + tinytag Audio header inspection, container metadata parsing, and format transcoding.
SQLite 3 Embedded SQLite database for indexing and searching audio files.
sentry-sdk Optional error reporting. Can be disabled in app settings.

Storage & Data Isolation

  • Data Locations: Database records and cache files reside exclusively within standard OS user-data directories (%APPDATA% on Windows, ~/Library/Application Support on macOS, ~/.config on Linux).
  • Non-Destructive Indexing: Audio folders are scanned in read-only mode. Source files are never modified, tagged, or moved on disk.
  • Timeline Export: Waveform trimming exports a temporary audio file into a cache directory; master files remain untouched.

Network & Privacy Policies

  • Offline Operation: Searching, indexing, waveform rendering, and timeline drag-and-drop work entirely offline without an internet connection.
  • No Audio Telemetry: Audio waveforms, file paths, library names, and sound files are never sent to external servers.
  • Error Reports (Optional): When enabled, error reports capture anonymized stack traces with send_default_pii=False. You can turn this off at any time in Settings (telemetry_enabled: false).

Development Context

I built MySoundLib independently because I edit videos and needed a faster way to find, preview, and cut sound effects directly on my timeline. The application is built with Python, Qt, and C-based audio libraries, using AI-assisted programming tools for coding and automated testing.
